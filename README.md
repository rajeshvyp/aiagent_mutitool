 Jarvis AI – Multi Tool Personal Assistant

 1. Objective
The objective of this project is to build an AI personal assistant using n8n that can interact with users through Telegram, perform tasks using different tools, and provide text or audio responses.

 2. Requirements (Tasks)
- AI Agent: Create an AI Agent using an OpenAI Chat Model to understand user requests and generate responses.
- Telegram Integration: Receive user messages through Telegram and send replies.
- Google Search: Search the web and provide relevant information and links.
- Amazon Search: Find products on Amazon and return product details and links.
- Google Docs: Create new documents and update existing documents automatically.
- Google Calendar: Create calendar events based on user requests.
- Text-to-Speech (TTS): Convert AI-generated text into audio messages.
- Conditional Routing: Use an IF node to send audio-only requests to the audio branch and normal requests to the text branch.
- Testing: Test each tool and verify that the workflow works correctly.

 3. What I Learned Today
- How to build an AI Agent workflow in n8n.
- How to connect Telegram with an AI Agent.
- How to integrate external tools such as Google Search and Amazon Search.
- How to create and update Google Docs and create Google Calendar events.
- How to convert text responses into audio using OpenAI TTS.
- How to use an IF node to control workflow execution based on user input.
- How to connect nodes, map data using expressions, and troubleshoot workflow errors.

 4. Conclusion
This project helped me understand how to combine AI, APIs, and automation tools in n8n to build a useful personal assistant. Jarvis can handle different tasks through Telegram and respond with text or audio depending on the configured condition.
